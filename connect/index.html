חיבור מספר וואטסאפ עסקי

חיבור במצב קואקסיסטנס: המספר ממשיך לעבוד באפליקציה בטלפון, ובמקביל המערכת יכולה לקרוא ולשלוח.

לפני שמתחילים

  1. המספר חייב להיות כרגע באפליקציית WhatsApp Business בטלפון, לא בוואטסאפ הרגיל.
  2. המספר לא מחובר כבר ל-Cloud API בשום מקום.
  3. הטלפון ביד, כי בסוף התהליך סורקים קוד QR מתוך האפליקציה.
אם מסך החיבור מציע אימות בקוד SMS במקום סריקת QR, זה המסלול הלא נכון: הוא מעביר את המספר ל-Cloud API ומנתק את האפליקציה בטלפון. לסגור את החלון ולעצור.
